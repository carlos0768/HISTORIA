## 4. 提案値であり実データ検証が必要なパラメータ

**すべて `algo_version` / `sched_version` で管理し、変更時は `response` から再計算する。**
値を直接いじって既存の状態を残す運用は禁止する（`04` §9、`03` §2.2）。

| 章 | パラメータ群 |
|---|---|
| `04-weakness-engine.md` §9 | `guess` / `slip` / `T_learn` / Elo の K / `n_eff` 閾値 1.5 / `mastery` 閾値 0.60・0.85 / `theta_0` = -0.5 / 診断の打ち切り条件 |
| `04b-spaced-repetition.md` §4.3, §6 | `median_latency` の初期値（四択12秒 / FC 6秒） / leech 閾値 `lapses >= 8` / 間隔上限365日 / jitter ±5% |
| `05-scheduler.md` §9 | `BUFFER_DAYS` = 3 / `MAX_DAILY` = 80 / 完了閾値 0.90 / 重複警告 40% |
| `06-assessment.md` §8 | 問数 = 範囲の35% / 弱点層70% : 習得層30% / 再出題禁止14日 / 目標正答率 0.60 / 再テスト3日 |
| `07-content-pipeline.md` §12 | 教材3,500字 / FC 10〜14枚 / 四択6〜10問 / judge 合格ライン |

## 5. 仕様として意図的に決めていないこと

「未決」ではなく「**決めないことを決めた**」もの。

| 項目 | 理由 |
|---|---|
| SLA・稼働率目標 | 個人開発・非公開のため定めない（`12` §5） |
| 論述・記述式の AI 採点 | 対象試験が共通テスト＋私大マークであり出題されない。**実装しないと決めた**（`01` §4.3） |
| 他ユーザーとの比較・ランキング | 母集団が成立しない（`01` §4.3） |
| チャット形式の質問応答 | ChatGPT の劣化版になる（`01` §4.3） |
| マネタイズ | 非公開・友人数人での利用。収益化しない |
| 多言語対応 | 日本の受験生のみが対象（`12` §9） |
