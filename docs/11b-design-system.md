# 11b. デザインシステム（Litverse 適用）

> 対象: HISTORIA MVP / 状態: 確定 / 最終更新: 2026-09-01

## 0. 決定

**HISTORIA の UI は Litverse Design System v1.0 を採用する。**

これにより `11-ux.md` の旧 §8（shadcn/ui ＋ Tailwind ＋ 単色アクセント＋グレースケール、
本文16px/1.8、lucide-react）は**破棄される**。

意匠は「**タイプライター用紙 × 髪毛罫 × 朱 ＋ 蛍光イエロー**」。全書体が等幅であり、
影とグラデーションを使わない。世界史という主題、および長文の教材を読ませるという用途と適合する。

### 1.1 デスクトップ版（2026-09-02 受領）

| | 値 |
|---|---|
| 幅 | 1440–1920（基準 1440×900） |
| シェル | **三分割**。サイドバー 240 ／ 本体可変 ／ 資料 320 |
| グリッド | 12列・溝 24px |
| ポインタ前提の調整 | タップ領域 44→32px ／ 本文 14→15px ／ 見出し 22→26px ／ テーブル行 36px |
| 追加コンポーネント | 資料テーブル、地図ワークスペース、コマンドパレット（⌘K） |
| 地図のクラス | `lvd-*`（land / border / grat / sphere / pin / route / lbl / marker） |

**採らないもの。** 設計系は地図に Leaflet + OSM タイルと、実行時の d3 / topojson（unpkg）を
使っている。どちらも `proxy.ts` の CSP が許していない。§4.1 と同じ理由で、地図は
**ビルド時に投影してパス文字列だけを出す**方針を保つ（`scripts/map/build-basemap.mjs`）。
`litverse-map.css` に入っている Leaflet 向けの記述は、資産としては原本のまま置くが実装では使わない。

**地形データの解像度。** 設計系は Natural Earth 50m を指定している。
`countries-50m.json` は 756KB（現行の 110m は 108KB）で、生成される基図も数倍になる。
モバイル回線が前提（§7.1・`docs/14` M15）なので、**50m はデスクトップの地図ワークスペース専用**とし、
動的 import で切り離す。モバイルは 110m のままにする。

| `--lv-ink` 墨 | `#171512` | 本文・罫線・枠 |
| `--lv-ink-soft` 墨(弱) | `#3A342C` | 長文本文 |

| `--lv-accent` 朱 | `#F4703C` | 主要ボタンの面・選択中 |
| `--lv-accent-press` 朱(押下) | `#DC5A28` | hover / active |

**使用比率: 紙 70% ／ 墨 20% ／ 朱 7% ／ 蛍光 3%。**
蛍光は1画面につき1箇所までとする。HISTORIA では「今日やること」と「あなた向けのポイント」に割り当てる。

**禁止: 影・グラデーション・第三の彩度色。** `box-shadow` と `linear-gradient` を書かない。

### 2.2 余白・罫線・角丸

```
余白   4 の倍数のみ（4 / 8 / 12 / 16 / 24 / 32）
罫線   1px 実線（リスト区切り）／1.5px（カード外周）／1px 破線（補助区切り）
角丸   0 / 4 / 6 / 26（端末枠）/ 全（999）
```

### 2.3 書体

```
和文  "M PLUS 1 Code"  →  ui-monospace, monospace
欧文  "Space Mono"     →  ui-monospace, monospace
```

| 種別 | サイズ | 太さ | 行間 | 用途 |
|---|---|---|---|---|
| display | 32px | 700 | 1.3 | 数値・画面の顔 |
| title | 22px | 600 | 1.4 | 画面タイトル |
| heading | 16px | 600 | 1.6 | 小見出し・設問文 |
| body | 14px | 400 | **1.9** | 本文 |
| caption | 12px | 400 | 1.7 | 補足・メタ情報 |
| label | 11px | 600 | 1.0 | 欧文ラベル（大文字・字間 +0.24em） |

組版規則:
- 和文の行間は 1.9〜2.0、欧文は 1.5
- 字間は既定 0。欧文ラベルのみ +0.24em
- **一画面につき書体ウェイトは3種まで**
- **リンクは下線のみ。色を変えない**
- 太字は見出しと数値にのみ使う

### 2.4 タップ領域

最小 44×44px。`--lv-touch` で定義済み。

## 3. アクセシビリティの修正（`historia-overrides.css`）

**Litverse をそのまま使うと WCAG 2.1 AA を満たさない箇所がある。** 実測した。

### 3.1 コントラスト比の実測

| 用途 | 前景 / 背景 | 比 | AA本文 4.5 | 判定 |
|---|---|---|---|---|
| 本文 | 墨 / 紙 | **16.91** | ✅ | |
| 長文本文 | 墨(弱) / 紙 | **11.41** | ✅ | |
| キャプション | 補助 / 紙 | **6.52** | ✅ | |
| 蛍光面の文字 | 墨 / 蛍光 | **13.80** | ✅ | |
| 押下背景の文字 | 墨 / 台紙 | **14.44** | ✅ | |
| **主要ボタン** | 紙 / 朱 | **2.70** | ❌ | **大文字基準3.0すら満たさない** |
| **タブバー選択中** | 朱 / 紙 | **2.70** | ❌ | 非テキストUIの3:1も満たさない |
| **エラー文言** | 朱(押下) / 紙 | **3.52** | ❌ | |
| **補助文字・プレース** | 鼠 / 紙 | **3.65** | ❌ | |
| 無効ボタンの文字 | 鼠 / 台紙 | 3.12 | ❌ | 無効UIは要件対象外のため許容 |

> ※ デザインキャンバスは「墨 on 紙 = 15.8:1」と記載しているが、
> WCAG 2.x の相対輝度式で計算すると **16.91:1** である。いずれにせよ十分に上回る。

### 3.2 上書きの内容と根拠

| # | 上書き | 根拠 |
|---|---|---|
| **A-1** | 主要ボタンの文字を**紙 → 墨**に変える | 紙 on 朱 = 2.70 → 墨 on 朱 = **6.27** ✅。朱の面は残るのでボタンの識別性は失われない |
| **A-2** | **鼠は罫線・非テキスト専用**にする。文字には補助を使う | 鼠 3.65 → 補助 **6.52** ✅。既存トークンのみで解決 |
| **A-3** | 朱を文字色に使う箇所は**朱(濃) `#CB420B`** にする | 紙上で **4.51** ✅。色相17°・彩度89%は朱と同一で明度のみ 59.6%→42.1%。**第三の彩度色ではなく朱の階調**である |
| **A-4** | タブバーの選択中を色だけで示さない（墨＋太字＋朱の下線） | 朱 on 紙 = 2.70。色は補助的な指標に留める |
| **A-5** | 再生バー（HISTORIA では学習の操作バー）の文字も墨にする | A-1 と同じ理由 |
| **A-6** | `:focus-visible` に必ず可視のリングを出す | キーボード操作 |
| **A-7** | 文字サイズを **rem** に読み替える | Litverse は px 固定。OS の文字サイズ設定に追従させる |
| **A-8** | `prefers-reduced-motion` を尊重する | |
| **H-1** | 習熟度バーの「弱い」塗りを**朱(濃)**にする | 朱 on 紙 = 2.70 は非テキストUIの下限 3:1 を満たさない |

**紙 on 朱 を 4.5:1 にするには朱を `#CB420B`（明度 -29%）まで暗くする必要があり、もはや別の色になる。**
したがって「面を変える」のではなく「文字を墨にする」を選んだ。

### 3.3 色だけに依存しない

| 情報 | 色以外の手がかり |
|---|---|
| 正誤 | 選択肢キーの記号（A/B/C/D の丸）＋ 罫線の太さ ＋ 面の色 |
| 弱点の状態 | `hs-status` に**必ずラベル文字**を出す（弱い／あやふや／習得済み／未測定） |
| 習熟度 | バーの隣に**必ず数値**を出す（31% など） |
| タブの選択中 | 太字 ＋ 下線 ＋ 色 |

## 4. Litverse → HISTORIA のマッピング

Litverse は読書アプリの語彙で作られている。HISTORIA の機能へ次のように対応させる。

| Litverse | クラス | HISTORIA での用途 |
|---|---|---|
| 01 アカウント作成 | — | サインアップ（招待コード → Google → 生年月日 → 同意） |
| 02 ホーム | `lv-promo` | **「今日やること」を蛍光の訴求面にする**。1画面1箇所という比率規則と一致する |
| 02 ホーム | `lv-book` / `lv-card` | 進行中の集中特訓カード（習得バー＋読了バーの2本） |
| 03 作品詳細 | `lv-meta__row` | 集中特訓の詳細（範囲・締切・KC数・進捗） |
| 04 読書・再生 | 本文組版 | **教材ビューア**（`07-content-pipeline.md` の7セクション構成） |
| 04 読書・再生 | `lv-player`（朱の帯） | **学習画面の正誤フィードバック帯**に転用（文字は墨に） |
| 04 読書・再生 | 「Aa 文字設定」 | 教材の文字サイズ切替（§6） |
| 05 設定 | `lv-list__row` | 設定・アカウント削除 |
| 06 保存済み | `lv-chip` ＋ カード | **記録タブ**（弱点の一覧＋根拠） |
| 全画面 | `lv-tabbar` | ホーム / 特訓 / 記録 の3タブ |
| 全画面 | `lv-navbar` | 画面ヘッダー |

### 4.1 使わないと決めたもの

| Litverse の要素 | 判断 | 理由 |
|---|---|---|
| `lv-rating`（★） | **習得度に使わない** | ★は「評価」を意味する。習得度に使うと「この項目は星3の出来」と誤読される。専用の `hs-mastery`（罫線＋塗り＋数値）を作った |
| `lv-cover`（2:3 書影） | MVP では使わない | 教材ユニットに「表紙」を作る工数に見合う価値がない。Phase2 で検討 |
| 色付き絵文字（🔥📺📖 等） | **使わない** | 等幅・単色の意匠から浮く。Litverse が使う活字グリフ（⌂ ⌕ ❑ ☺ ← ↗ ⋮ ☰ ◔ ▶ ＋ ✎ ·）に統一する |
| lucide-react 等のアイコンライブラリ | **使わない** | 同上。アイコンは活字グリフで表す |
| shadcn/ui | **使わない** | Litverse CSS が同じ役割を果たす。2つのデザイン言語を混ぜない |
| ダークモード | **作らない** | 紙の意匠が前提。既存の決定（`11-ux.md`）と一致 |

## 6. 教材本文の可読性

**Litverse の本文は 14px / 行間 1.9 である。** 一方 HISTORIA の教材は1ユニット 3,500字（約7分）であり、
スマートフォンで読ませる。14px は小さめだが、Litverse は本文14pxを「読書画面の標準サイズ」と規定している。

**決定: 既定は 14px とし、教材ビューアにのみ文字サイズの切替を置く。**

```
教材ビューアのヘッダー右に「Aa」を置く（Litverse 04画面に同じ affordance がある）
選択肢: 14px（既定）／ 16px ／ 18px
行間は常に 1.9 を保つ。選択は localStorage に保存する
```

サイズは `rem` で定義してあるため（上書き A-7）、OS の文字サイズ設定にも追従する。

**着工前に実測すること**: 3,500字の教材を実機のスマートフォンで通読し、
14px で読み切れるか、読了率とスクロール到達率を計測する（`01-product.md` §6.2）。

## 7. 実装の指針

### 7.1 フォントの読み込み

```
和文  M PLUS 1 Code  weight 300/400/500/600/700
欧文  Space Mono     weight 400/700
```

**日本語の等幅ウェブフォントは容量が大きい。** Google Fonts の CSS2 API は
`unicode-range` による自動サブセット（woff2 のレンジ分割）を行うため、これを使う。

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Space+Mono:wght@400;700&family=M+PLUS+1+Code:wght@300;400;500;600;700&display=swap">
```

Next.js では `next/font/google` を使い、ウェイトは**実際に使うものだけ**を宣言する
（組版規則で「一画面につき3種まで」としているため、400 / 600 / 700 の3種で足りる可能性が高い）。

**要検証**: 初回表示時のフォント転送量を実測する。高校生がモバイル回線で使う前提であり、
数MBになるなら和文のウェイトを 400 / 700 の2種に削るか、システム等幅へのフォールバックを検討する。
`font-display: swap` は必須。

### 7.2 Tailwind を使う場合

`litverse-tokens.json` を `tailwind.config` の `theme.extend` に流し込む。
ただし **Litverse の `lv-*` クラスをユーティリティで置き換えない**。
コンポーネントは `lv-*` / `hs-*` を使い、Tailwind はレイアウト（flex / grid / 余白）に限って使う。
2つの語彙が競合すると、デザインシステムが1年で崩れる。

### 7.3 CSS の配置

```
app/
  globals.css          -- litverse.css と historia-overrides.css を @import（この順）
  layout.tsx           -- <body className="lv-root">
```

`lv-root` を `<body>` に置く。これが背景・本文書体・リンクの下線・選択色の基点になる。
